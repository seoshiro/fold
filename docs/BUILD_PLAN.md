# FOLD implementation contract

Visual source: supplied original FOLD concept pack, especially 00_APPROVED_FOLD.png. The artwork is a mood/composition reference, not orthographic geometry or factual evidence.

- One ivory paper crane on vermilion, distinct neck, beak, body and tail; cities stay physically attached to a folded wing.
- Thin paper shells, explicit pivots, stable scene and canvas. Art-directed pop-up mechanics, not a claim that everything is one uncut sheet.
- Build hinge proof and Kyoto end-to-end, then complete Lisbon and Almaty. Intermediate poses matter.
- Content: three sourced real locations per city, artistic arrangement, no schedules/distances/access guarantees.
- Real HTML interface: EN/RU/KK, stories, guided viewing, saved places, deep links, Back/Forward, accessible alternate controls.
- Separate intent/navigation from physical pose. One Three.js/GSAP owner for animated transforms. No timers to arbitrate camera races.
- Fonts: self-hosted Noto Serif + Noto Sans, SIL OFL (license in public/licenses). Explicit Cyrillic Extended subset includes Kazakh letters.
- Reduced motion, fallback using actual-model posters, safe local storage, no forced sound, no third-party tracking.
- Separate project/repository/free preview; other user projects remain untouched.

5. Public deployment verification, source assets, README/evidence.
